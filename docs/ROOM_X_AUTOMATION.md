# 楽天ROOM連動 X 自動公開運用

## 現在の状態

実装・画像生成・ローカルテスト・タスク設定プレビューまで完了しています。
Xの従量課金プログラム参加、クレジット購入、OAuth認証、Windowsタスク登録、
公開投稿はまだ行っていません。

## 週間スケジュール

- 月 09:10: すぐ試せる1工夫
- 火: 07:00生成で事前選定し、対象ROOM枠の公開5分後から15分間だけ宣伝
- 水 20:10: 保存用3項目
- 木: 火曜と同じ宣伝運用
- 金 09:10: 困りごとの前後を示す配置例
- 土: 火曜と同じ宣伝運用
- 日 20:10: 具体例と質問1つ

宣伝候補の準備は07:10、07:20、07:35に試みます。対象のROOM枠が朝なら
08:05/08:12、昼なら12:05/12:12、晩なら19:05/19:12に確認します。
準備が対象枠の時刻に間に合わなかった日は投稿しません。PC停止などで時刻を
逃した場合も遅れて投稿しません。

## 公開条件

宣伝投稿は次のすべてが一致したときだけ公開します。

1. 07:00生成成果で品質85以上、レビュー理由なし
2. 事前に選んだ商品・枠・商品URLが変更されていない
3. 本番DBで対象枠と送信記録がともに`posted`
4. ログイン済みROOM詳細ページの商品URLが完全一致
5. 本文に`#PR`があり、公式X APIへ`paid_partnership=true`を送る
6. 当日分の公開済み記録、結果不明記録、実行中記録がない

通信が切れて公開結果が分からない場合は`uncertain`として停止し、自動再送しません。

## 役立つ投稿

4種類×5本の計20本を用意しています。初期4週間の16本に加えて、各型1本の
予備があります。すべてオリジナルの1200×675画像を持ち、販売リンク、商品名、
`#PR`、医療・発達の断定、未使用商品の体験談を含みません。

## 初回導入で必要な確認

1. X Developer Consoleで従量課金プログラムを開始する
2. 月上限を決め、クレジットを購入する（自動チャージは初期OFFを推奨）
3. OAuth 2.0のcallbackを`http://127.0.0.1:8765/callback`へ設定する
4. `tweet.read users.read tweet.write media.write offline.access`だけを許可する
5. 認証後、暗号化トークン保存を確認する
6. 初回宣伝の公開直後にX画面で有料パートナーシップ表示を確認する
7. 表示がなければ以後の宣伝投稿を停止する

上記1〜5は外部サービス・認証・課金を伴うため、社長確認後に実施します。

## 安全な撤去

Windowsタスク`RakutenROOMXPublisher`を無効化すれば新規公開は止まります。
既存のROOM投稿、ROOM台帳、ROOM本番DB、Xの既存投稿は変更しません。
